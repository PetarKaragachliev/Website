# BG/EN Interface

Publishing is now owner-approved; the GitHub workflow gates the preview deployment. The local-only descriptions below record the verified pre-publishing milestone.

The owner-requested BG/EN dropdown is implemented locally on nutrition and training, not published. Top `details#language-toggle` shows only the current language (BG by default) and a chevron; opening it reveals the other language below. Selection closes the dropdown; Escape and outside clicks dismiss it. Keyboard selection and focus return are supported. Language options retain `data-language="bg"` and `data-language="en"`. Scientific names, LiftFuel branding, the requested Skinny Fat term, and original external sources retain their names.

Bulgarian source HTML/model text and existing `i18n.js`, `bg-models.js` and `bg-app.js` translations are retained. `public/js/language.js` and local English catalogs translate static and dynamic presentation, including numbers and accessible attributes, without changing calculations, profile schemas or input parsing. No translation service or profile upload is used. Switching needs no reload and preserves inputs, results, loaded iframes and disclosure state. RFM retains one display decimal.

The guarded `liftfuel.language` choice is independent of optional health-profile remembering. Unavailable storage still permits switching for the visit and reports failed saving. Explicit data deletion removes the language key and resets BG only if that removal succeeds, without deleting unrelated browser data or masking retained-profile failures. Profile v6 and v1-v5 decoding remain unchanged; see BODY_ASSESSMENT.md.

Common age, weight, goal and outside-training activity are entered only on nutrition; training shows shared context and collects only its six settings. Bulgarian labels distinguish base/rest intake, training-day intake and estimated extra energy, never measured burn. Daily kcal round to nearest 10, grams to whole numbers, with unchanged internal precision. Explain unavailable energy/support limits without implying exercise is forbidden; no invented pace when all options are blocked. Sources/method: [TRAINING_ENERGY_POLICY.md](TRAINING_ENERGY_POLICY.md).

Earlier switch scenarios were retired under the previous Bulgarian-only contract; that historical evidence remains unchanged. The restored switch is covered by four presentation unit tests and eight browser scenarios across all five projects: round trips, unchanged inputs/results/consent/storage, navigation, workouts/tables, iframe identity, errors, blocked storage, deletion, startup failures and 320px reflow. `npm test` passed all 431 tests; `npm run test:e2e -- --reporter=line` passed all 630 checks. No health data belongs in URLs or persisted results. No screenshots, video or traces were generated. No commit/push was requested for this feature.

Dropdown follow-up: two new scenarios failed before implementation (missing summary trigger), then all 50 language checks passed across the five browser projects. Unit tests were rerun successfully. The full non-language browser matrix was not rerun for this dropdown-only change.
